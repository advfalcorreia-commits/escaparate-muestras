    Falta la clave de Google Places

    La búsqueda en tiempo real usa la Google Places API — la misma que el SitesLead. Pega aquí tu clave y queda guardada solo en este navegador: no viaja al repositorio ni a ningún servidor nuestro.

    Cómo conseguirla
    1. Google Cloud Console → nuevo proyecto.
    2. Activar Places API (New).
    3. APIs y servicios → Credenciales → Crear clave de API.
    4. Restringir la clave a Sitios web con el dominio de la demo.
    5. Pegarla arriba. Cuesta ~32 USD por 1000 búsquedas de 20 resultados.
